Import from a spreadsheet

Save your current fish list as CSV. Columns are matched by name: stock, line, name, room, location (rack/tank), PIL, PPL, severity, fertilisation date (YYYY-MM-DD or DD/MM/YYYY), fluorophores, total fish, females, males, comments. Imported stocks are assigned to you; change the responsible person afterwards if needed.

Backup

Download everything (stocks, crosses, plans, fish numbers and change history) as one file. The lab's database is also backed up automatically every week. Import adds back items from a backup file, including one downloaded from the old Claude version; it never overwrites what's already here.

Deleted items

Deleting a stock or a cross moves it here, so a mistake can be undone. Only the lab owner can delete items for good.
